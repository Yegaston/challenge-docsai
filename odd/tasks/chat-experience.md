# Chat Experience

## Objective
Turn successful but unhelpful transfer clarifications into actionable, language-appropriate chat. Improve the customer and support thread UX, provide quick choices for missing transfer details, and deliver a genuine incremental HTTP stream of the server-approved final answer. Preserve the existing authenticated, idempotent, owner-scoped agent and four-hour handoff semantics.

## Context and constraints
The observed `POST /api/conversations` returned a 201 conversation with `clarificationDeadline` and an English generic clarification for the Spanish question about a transfer sent today. This is not an HTTP error: the current agent discards model prose and cannot look up a transfer without exact amount/date or ID. Do not fabricate a financial status or imply synthetic data is real bank data. Tool results and status claims must remain server-grounded. Keep existing JSON routes compatible; no real provider invocation without cost approval. The stream should expose a checking state and then incremental verified text, with no false claim of raw LLM tokens during tool work. Explicit choices must be structured metadata, never parsed from model prose. Separate provider failure, no match, and clarification states. Preserve per-user rate limit, idempotency, persisted history, reply cancellation, support access and 90-day retention. User-owned untracked `.agents/` and `skills-lock.json` remain untouched. Existing feature/tracker branch chain is the delivery strategy; no push/PR/merge.

## Acceptance criteria
The reported Spanish prompt receives an understandable Spanish clarification, not an English generic fallback, and presents concrete choices to identify a relevant synthetic transfer when available or a clear path to provide amount/date or ID and request human help. Transfer status is asserted only for a selected/verified owner record. A conversation shows a checking state and incremental server-approved text, persists the same final message on reload, and never turns an uncertain transport outcome into a new charged call automatically. Quick choices work by keyboard and pointer and remain available on reload. Support human messages remain visible in the same thread without triggering AI.
